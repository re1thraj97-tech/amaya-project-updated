# AMAYA Project — Updated Client Version

Updated client version of the AMAYA copper exploration website.
Black premium design (from the original) + the information hierarchy and data
presentation of the white/corporate reference version.

## Structure (5 pages, shared chrome)

| File | Contents |
|---|---|
| `index.html` | Hero, key figures, project snapshot, section navigation |
| `project.html` | 9-concession table, geology (West Fault), exploration timeline |
| `location.html` | Calama Airport + export port distances, neighbouring operations |
| `market.html` | Indicative copper reference price, demand context |
| `about.html` | Leadership placeholders, responsible exploration, contact |
| `styles.css` | Shared stylesheet (cached across pages) |
| `app.js` | Shared script: mobile menu, reveals, counters, hero canvas |

## Key project figures

- 9 copper concessions
- 2,353 hectares
- 5,814 acres
- 3,800 m above sea level, 80 km north of Calama, Atacama Desert, Chile
